# Brand kit: Yoko Ono Asian Kitchen (יוקו אונו) + Sushi Push Pop (סושי פוש פופ)

> **Shortcut:** "Sushi Push Pop" / "סושי פוש פופ" = this folder. Never ask the user for the logo, product, or how-to again.
> Everything here is also in the Higgsfield media library (IDs below), ready to pass into `medias[]` without re-uploading.

## The brand
- **Restaurant:** Yoko Ono, Asian Kitchen. Japanese ヨーコ・オノ appears on the label.
- **Logo:** gold line-art arch with cherry blossoms, a mountain, "YOKO ONO / ASIAN KITCHEN", and a bowl with chopsticks over waves.
- **Palette:** matte black + gold (#D6B26E). There's a red "YO" square badge on the label.
- **Sushi Push Pop** is a Yoko Ono product.

## The product: Sushi Push Pop
A matte black cardboard tube with the round logo label and gold "Sushi push pop" text.
A clear soy-sauce vial is clipped to the side. The roll sits inside, and you **push it up from the bottom**.

**How to use it** (also printed on the label and the stickers):
1. Remove the soy vial from the side (מוציאים את הסויה).
2. Open the clear lid (פותחים את המכסה).
3. Pour soy on top (מוסיפים סויה).
4. **Push up from the bottom** and enjoy (דוחפים למעלה ונהנים!).
