# Sushi Push Pop: "Anywhere" (draft v1)

**Idea (from the user):** A kid walks in locked side profile. The camera never moves, but the world behind him keeps changing: snow mountain → desert → sea → Amazon jungle. Each time he arrives somewhere (summit, beach, cliff over the jungle), he pulls out the Sushi Push Pop. Close-up: the push pop rises into frame, the backgrounds cycle behind it, and he pushes it.
**Message:** sushi that goes with you anywhere.
**Format:** 9:16, about 15s at 24fps, plus a 6s cutdown (product beat only).

## The device: the frame stays, the world changes
The same trick is used three times so it reads as one idea:
1. **Walk swap:** profile walk, and the world changes on every footfall or jump.
2. **Arrival swap:** he sits in the same pose and spot in frame, and only the view changes (summit → beach → jungle cliff).
3. **Product swap:** close-up of the push pop with the worlds flashing behind it, then it locks on one.

## Production approach
- **Consistency first:** build a character sheet of the kid in profile and three-quarter view before any shot. Every clip uses it as a reference.
- **Hide the joins:** transitions happen behind foreground objects (drift, spray, leaves), not on the kid. That way small AI differences between clips don't show.
- **Product truth:** the push pop must be the real product. The macro shot is built from real product photos, either composited or used as a strong image reference, so the AI doesn't invent packaging.
- **Sound carries it:** each world gets its own texture (crunch / sand hiss / waves / jungle birds), all on one score. "POP" is the loudest moment in the spot.
